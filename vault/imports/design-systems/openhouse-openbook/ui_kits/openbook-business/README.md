# OpenBook Business — UI Kit

Operator dashboard. Dark-mode default. Linear/Stripe/Vercel-grade density and speed.

**Demonstrated in `index.html`:** sidebar nav, KPI stat cards with sparklines, dense bookings table with per-row MCP attribution, command palette (⌘K), MCP live panel, top-services panel.

**MCP source attribution** (gold `bolt` badge) is the single distinctive flourish — every booking sourced through an AI agent (Claude / ChatGPT / Gemini) is tagged.
