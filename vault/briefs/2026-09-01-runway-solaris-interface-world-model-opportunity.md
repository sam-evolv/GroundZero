# Runway Solaris interface-world-model opportunity

## Disposition

Keep Solaris on the capability radar and resurface it when public access, production integration, pricing, rights and reliability improve. Do not divert the current Donworth Studio or Aire delivery paths, apply for access, integrate the model, upload client material or incur spend without a new explicit decision.

## Verified source facts

Runway introduced Solaris on 31 August 2026 as the first model in a proposed family of **Interface World Models**. It generates an interface visually, frame by frame, at interactive speed rather than translating a design into a conventional coded representation. Runway describes a language model handling intent and behavior while the world model continuously renders the visual state at 720p.

Runway says Solaris is currently strongest at ambient motion, click-and-drag interaction and scene transitions. Its own stated limitations include stable legible text, factual trust, long-session coherence, accessibility and integration with the wider software stack.

At capture time, the announcement offered partner/early-access requests rather than general access. Solaris did not appear in Runway's public API model catalogue or public pricing surface, so API shape, availability, licensing and production economics remain unverified.

## Potential future opportunity

The most credible Donworth Studio wedge is an **adaptive visual sales and demonstration layer** for visually rich businesses such as property, interiors, hospitality and retail. Solaris could let a customer manipulate a grounded product or environment rather than navigate fixed pages.

The commercial architecture should remain hybrid:

- Solaris or a successor for immersive, adaptive visual interaction;
- verified client imagery and product data for grounding;
- conventional deterministic software for facts, prices, forms, accessibility, transactions and auditability;
- a reliable fallback whenever generated output is uncertain or unavailable.

For Aire, the later opportunity is contextual visual guidance or interactive tutorials that render the next step around a user's task. It should not become a core dependency until reliability, integration and economics are proven.

## Resurface triggers

Reassess when one or more of these becomes true:

1. Solaris receives a documented public or partner API suitable for an isolated prototype.
2. Production pricing, data-handling terms and commercial rights become explicit.
3. Stable text, accessibility and long-session coherence materially improve.
4. A committed Donworth client has a high-value visual demonstration problem that conventional interfaces solve poorly.
5. Aire has a validated recurring workflow where contextual visual guidance could measurably improve task completion.

## Smallest future test

Use only approved synthetic or non-sensitive assets to build one bounded, non-transactional demonstration. Compare it with a conventional coded version on task completion, factual error rate, accessibility fallback, latency, user preference and cost. Do not connect it to production systems or customer data during the first test.

## Open gaps

- Public or partner API availability
- Price per interactive session and hardware/runtime requirements
- Commercial licensing and generated-output rights
- Data retention and training-use terms
- Deterministic integration, session recovery and auditability
- Accessibility API support
- Factual grounding and failure detection
