# Personal agent founder operating brief

## One-sentence thesis

Package the existing power of Hermes and Sam's Ground Zero-style personal context into an assistant ordinary people can start using in minutes, then use the agent-built company and its real outputs as the proof and distribution engine.

## What is being built

A subscription personal assistant that:

- uses Hermes as the underlying agent runtime;
- retains persistent conversation, tools, approvals, sessions, memory and routed models;
- is reachable through a simple web, desktop and eventually native mobile experience;
- progressively understands the user's life and work through an inspectable personal context layer;
- completes bounded work rather than stopping at chat;
- asks before consequential actions;
- hides command lines, providers, bot setup and agent-framework terminology.

## Non-negotiable product rule

Do not replace Hermes with a narrower engine merely because that path is easier to constrain or demonstrate. The first usable product must preserve the breadth Sam already finds valuable. Simplification happens above and around the runtime.

## Build sequence

1. **Clone the working experience:** get the Hermes-backed wrapper usable through web and desktop with real sessions, streaming, tools, approvals, artifacts and memory.
2. **Founder dogfood:** Sam uses it as his own assistant across real tasks. Record friction and failure honestly.
3. **Simplify from evidence:** remove technical concepts, improve onboarding and reshape the interface based on observed use.
4. **Home-screen continuity:** make the web product installable and fast to access on phone before native store builds.
5. **Personal context:** evolve the Ground Zero concept into an inspectable user context surface without exposing vault mechanics.
6. **Native apps:** build iOS and Android once the interaction model has earned stability.
7. **Model economics last:** choose and route models after measuring real workload, quality and cost. Keep providers invisible to ordinary users.

## Founder-led proof loop

The company should demonstrate itself:

- the agent helps build the product;
- the agent produces design, research, software and operational outputs;
- each verified capability becomes a high-quality proof asset;
- Sam documents that the product and its marketing are being built with his own agent;
- nothing is published without Sam's approval;
- proof always shows a completed outcome, not a tool log or autonomy claim.

The strongest public frame is not “AI built this alone.” It is “I built an agent that materially helps me, and together we are turning that capability into a product anyone can use.” This is credible, durable and does not erase Sam's founder judgement.

## Pricing hypothesis

Test an accessible entry plan near €4.99 per month for routine text-based assistance, with a target variable model cost below €1 per active user per month. Premium models, media generation and long-running work remain separate allowances or higher plans.

This price is not yet commercially validated. Support, payments, hosting and tool execution can exceed inference cost. Instrument cost and support before committing publicly.

## Immediate acceptance test

Sam can open the preview without a terminal, start or resume a real Hermes conversation, complete several materially different tasks, see genuine progress, handle a real approval, receive a result or artifact, and continue the same context later.
