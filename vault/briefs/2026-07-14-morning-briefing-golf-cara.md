## Cara — founder dogfood direction to validate

Sam’s instinct is to use Telegram as Cara’s first founder-control and messaging surface because the existing Hermes/Telegram stack already works well for text, asynchronous tasks and voice messages. This should reduce cost and friction while proving the useful core: memory, task continuity, proactive follow-up, voice-note handling and post-conversation artefacts.

Important distinction to verify before changing the product route: Telegram Bot API supports bots, messages, voice notes and media, but the official Bot API does **not** expose a bot voice-call interface. Therefore:

- Telegram is a strong **text + voice-message + task-control** founder dogfood surface now.
- It is not a replacement for the planned hands-free, live, barge-in-capable phone/WebRTC voice loop.
- The correct sequencing is likely Telegram Cara for daily usefulness and durable memory/task testing, while the realtime voice benchmark remains a separate focused lane.
