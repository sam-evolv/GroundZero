# Solar installer software wedge

## Core thesis
The best version of the solar idea is **not** a solar install company.
It is software that helps solar installers sell, survey, design, install, and support systems with fewer truck rolls and less admin.

## Why this is attractive
- The installer market already has demand for faster design, remote quoting, and plan-set generation.
- The software layer is much easier to scale than hiring roof crews and electricians.
- The value is clearest when the software reduces site visits, shortens proposal time, and centralises post-install support.
- The post-install layer can extend into heat pumps, HVAC, and other home energy assets.

## What existing players already cover
- **Aurora Solar**: sell, design, finance, and deliver solar/storage; strong on remote design and faster proposals.
- **OpenSolar**: free design/sell/manage platform; remote design and integrated project workflow.
- **Scanifly**: solar design + field ops; mobile site capture; wireframes; plan sets; drone-assisted workflows.
- **Enphase**: installer docs, training, monitoring ecosystem, warranty/support around microinverters and apps.

## Key market reality
Remote solar design and quoting are already competitive. A new entrant should **not** try to win on roof measurement alone.
The wedge has to be something the current tools do less well:
- customer lifecycle management
- post-install monitoring
- asset-level support
- service triage
- scheduling
- multi-asset home energy dashboards
- warranty and evidence trails

## Best product wedge
### 1. Pre-install
- remote roof feasibility / shading / budgetary quote
- site-survey checklist
- document capture
- permit-ready evidence pack

### 2. Install
- installation planning
- electrician scheduling
- job status visibility
- issue logging
- change-order capture

### 3. Post-install
- uptime monitoring
- anomaly detection
- customer support triage
- warranty / service routing
- unified dashboard for solar + heat pump + HVAC

## Rough value estimate
Illustrative conservative estimate:
- **€95 to €455 per install** in direct value
- midpoint around **€275 per install**

At **30,000 installs/year**:
- **€2.9M to €13.7M** in annual value
- midpoint around **€8.2M**

Potential pricing:
- €25/install -> €0.75M ARR at 30k installs
- €50/install -> €1.50M ARR
- €75/install -> €2.25M ARR
- €100/install -> €3.00M ARR

## Recommendation
Build this **only** if the wedge is narrow and operational:
- not generic solar design software
- not a full solar installer business
- not a broad home-energy OS on day one

The best first version is probably:
**"customer + asset + support layer for solar installers"**
with remote capture, monitoring, triage, and scheduling.
