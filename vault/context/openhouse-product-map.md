# OpenHouse product map

## What it is
OpenHouse is an AI-powered property platform for developers and purchasers.

## Core product surfaces

### 1. Developer Portal
The main operating surface for property developers.
It includes:
- overview dashboard
- homeowner / unit management
- pipeline and development views
- schedule and calendar tools
- issues and snagging workflows
- communications and message templates
- compliance views
- knowledge base / archive
- analytics and insights
- AI assistant and scheme intelligence
- pre-handover and setup tools
- document / Data Hub integration

### 2. Smart Archive / Data Hub
A document layer for connected folders and compliance content.
It is used to:
- connect Google Drive or OneDrive
- sync files into the platform
- classify files by category such as drawings, compliance, specs, commercial, other
- watch folders per development
- surface missing or weak document coverage

### 3. Homeowner / purchaser support
The platform also serves homeowner aftercare and communication.
It supports:
- homeowner accounts / issue handling
- warranty flows
- document access
- notifications
- completion, snagging, and aftercare messaging

### 4. AI assistant and insights
The platform uses chat and AI surfaces to answer homeowner questions and show knowledge gaps.
It tracks:
- what homeowners ask
- what the system could not answer
- where documents are missing
- engagement and onboarding activity
- handover readiness

## Real job of the product
OpenHouse is not just a portal.
It is a developer operating system for:
- handover
- documentation
- homeowner education
- aftercare
- compliance evidence
- issue handling
- communication
- insight generation

## Selling language that is true to the product
- prove the handover happened properly
- make aftercare easier to manage
- turn documents into usable evidence
- improve buyer experience
- reduce support friction
- create a cleaner sustainability and compliance story
- centralise the operational truth of the scheme

## Useful shorthand
If a person asks what OpenHouse does, say:

"It helps property developers manage handover, documents, homeowner communication, compliance evidence, and aftercare in one system."
