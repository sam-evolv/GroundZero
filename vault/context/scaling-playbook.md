# How to use Ground Zero to scale the businesses

## Core idea
The vault should not just store context. It should become the system of record for:
- what matters
- what is true
- what is decided
- what is next
- what can be automated

That lets any model work faster, stay consistent, and generate better leverage over time.

## High-value uses

### 1. Executive memory
Store durable facts once:
- business facts
- customer facts
- strategy decisions
- preferences and working rules
- current priorities

This keeps every model aligned and stops repeated explanation.

### 2. Company operating system
Use company notes plus project_state, goals, items, and decisions as the live operating layer.
That gives you:
- a clear current state
- a backlog of active work
- a log of decisions
- a record of what was tried

### 3. AI briefing pack
Any model should be able to start from:
- [[context/index]]
- [[context/model-pack]]
- [[context/business-opportunities-moc]] — MOC for all wedge ideas
- [[briefs/ai-money-patterns-2026-06]] — pattern context
- [[goals/oh-funder-pitch]] — funder narrative
- [[companies/openhouse-ai]] — primary company
- [[people/sam-donworth]] — founder context
- the relevant company note
- the relevant project_state note
- the current item or decision note

That means Claude, Gemini, ChatGPT, Hermes, and future tools can all get the same grounding.

### 4. Decision capture
Every important call should become a decision note.
That prevents re-litigating old choices and makes future reasoning faster.

### 5. Research and synthesis engine
Use the vault to collect:
- customer pain points
- market opportunities
- product ideas
- automation ideas
- competitor observations

Then ask a model to synthesize patterns into priorities or experiments.

### 6. Workflow automation source
The vault can drive automation:
- cron jobs read the latest notes
- briefings summarize what changed
- tasks can be generated from gaps
- agents can draft follow-up actions from decisions and project state

### 7. Founder leverage
The most valuable use is not admin. It is leverage:
- less repetition
- faster strategic thinking
- cleaner handoffs between models
- fewer dropped threads
- more time on sales, product, and execution

## Recommended structure

### Keep these as the core sources
- `people/` for Sam and other recurring people
- `companies/` for each venture
- `project_state/` for current status
- `goals/` for desired outcomes
- `items/` for active work
- `decisions/` for durable decisions
- `briefs/` for dated summaries
- `context/` for shared entry points and model packs

### Use this rule
If a fact is stable, file it once.
If it changes, put it in project_state or an item.
If it is a choice, put it in decisions.
If it is temporary, keep it in capture/inbox.

## What this unlocks
- better context across chats
- reusable company memory
- faster planning
- more consistent model behavior
- a real operating system for the businesses

## Best next move
Keep populating the vault with:
- company facts
- customer facts
- working rules
- current priorities
- decision history
- active tasks

Then wire the most important notes into MCP and any AI entry point so every model can read the same source of truth.
