# Personal agent project state

## Current state

- Working repository: `/Users/samdonworth/Projects/IrelandGPT`.
- Hermes API Server is enabled on loopback and listening locally.
- The repository now contains a responsive browser conversation desk, local backend-for-frontend and Hermes API client for sessions, history, runs, SSE progress, approvals, recovery and stop.
- The full Python suite passed 102 tests outside the coding sandbox after a history-role boundary fix.
- Five implementation commits exist locally; no production deployment or push was performed during the runtime-first build.
- The selected-folder connector and SwiftUI simulator app remain in the repository as secondary/reference work.
- Hark Handoff has been studied against its launch video, technical article, public leaderboard and privacy policy. The adopted direction is a calm handoff desk: durable task identity, Doing, Done receipts, missing-detail states distinct from approvals, an inspectable You surface and bounded isolated browser execution.
- The 6 August product strategy session is now adopted as the design charter: IrelandGPT is a delegation-first personal operating system, with invisible models, just-in-time connectors, completed hated jobs as the first-use test, and time returned as the value proposition.
- The IrelandGPT preview server still needs to be started with the live API key and exercised through a real Hermes conversation before the wrapper is accepted.
- Final product name remains open.

## Active objective

Make the real Hermes-backed wrapper usable enough for Sam's daily founder dogfood. Prove varied tasks, continuation, approvals, results and mobile home-screen access. Record friction and improve the product from evidence.

## Current blockers

- The BFF is not yet confirmed as a persistent background service.
- A live real-Hermes conversation through the browser has not yet been recorded in the evidence log.
- Generic file artifact delivery is deferred because the current Hermes API seam lacks a safe general artifact registry.
- Native mobile development is intentionally sequenced after web and desktop dogfood.

## Next verified milestones

1. Start and health-check the IrelandGPT BFF on loopback.
2. Complete one real simple Hermes turn through the browser.
3. Complete one tool-using task with genuine progress.
4. Exercise a real approval and stop/recovery path.
5. Install the web app to the phone home screen and test continued use.
6. Capture screenshots, latency, failures and friction.
7. Convert verified outcomes into product and marketing proof assets, without publishing.
8. Reshape the existing conversation run into a durable task card with a completion receipt before adding broad browser execution.
9. Implement one appointment-letter-to-calendar contract after Hermes exposes a safe artifact registry.
10. Research and rank the first Irish administrative wedges by pain, frequency, feasibility, consequence and willingness to pay.
11. Redesign first use around one completed hated job with a just-in-time permission request, real progress and a final receipt.
12. Instrument time-to-first-completed-outcome, repeat delegation, approval comprehension, recovery success, trust failures and cost per completed outcome.
