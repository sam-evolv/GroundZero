# IrelandGPT full Hermes Desktop parity

## Outcome

IrelandGPT reproduces every useful Hermes Desktop outcome through the current branded responsive web/mobile shell before further consumer simplification. Hermes remains the engine and source of truth.

## Acceptance rule

A capability counts as parity only when:

1. It uses a real Hermes resource or trusted paired-desktop execution path.
2. The browser receives a product-owned, privacy-filtered projection.
3. Every control has loading, empty, offline, approval, failure and recovery behavior where relevant.
4. It completes a real outcome in the browser or paired-device path.
5. Exact method and route contracts are enforced across client, BFF, relay and public proxy.
6. No raw prompts, commands, filesystem paths, credentials, provider metadata or unrestricted host controls cross into the consumer browser.
7. The exact immutable candidate is independently reviewed before deployment.
