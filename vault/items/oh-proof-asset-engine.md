## What this is
A small, fixed set of reusable proof assets built once from the live Longview Estates deployment, then reused across every investor conversation, developer pitch, funding form, and award application. Not a build project. A content and evidence packaging slice.

Target asset set (deliberately minimal):
- One metrics snapshot one-pager: live schemes, homeowner accounts, handover/aftercare activity, response-time and resolution figures that are actually true today.
- One anonymised developer reference case: the Longview story as a repeatable narrative (problem, rollout, outcome), cleared for external use.
- Two to three verbatim homeowner or developer quotes, with permission logged.

## Opportunity size
High leverage for low effort. Outreach and funding are the committed focus this cycle, and warm demand already exists via the Bridgewater five-scheme introduction. Conversion of investors, developers, and grant assessors is gated on credible, specific proof, not on more product. One clean evidence pack lifts the conversion of every downstream conversation and every application, so the payback is immediate and compounding.

## Technical approach
- Pull only figures that are verifiable from the live system; do not assert numbers the data cannot support (the 24 July market-readiness audit is a reminder to under-claim).
- Draft the one-pager, reference case, and quote sheet as plain reusable content.
- Get explicit permission for any named developer or homeowner reference before external use.
- Store the assets where the deck, site, and application drafts can all draw from them.

## Risks
- Over-claiming. The market-readiness audit shows OpenHouse is not yet safe to present as enterprise-rollout ready, so proof must stay strictly to what is live and true.
- Permission gaps. A developer or homeowner quote used without sign-off is a relationship risk.
- Staleness. Figures need a light refresh cadence so the pack does not drift from reality.

## Effort
S. This is packaging existing truth, not building. The slow part is securing reference permission, not producing the content.

## Market timing
Timely. Investor and developer outreach is live now and Bridgewater is a warm, high-fit prospect. Proof assets are most valuable in the window before those conversations happen, which is now.
