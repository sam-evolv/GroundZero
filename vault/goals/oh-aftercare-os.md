# Goal: Turn OpenHouse into the AI aftercare operating system

OpenHouse should move from a set of portals to a single property intelligence layer that understands the home, the owner, the developer, and the work history.

The product opportunity is not more UI. It is a property-linked AI layer that can:
- identify the user and surface the right workflow instantly
- read photos, documents, and messages in one context
- classify issues automatically and route them to the right team
- learn recurring defect patterns by unit, phase, and subcontractor
- give developers a premium control center instead of a generic portal

## Product direction

1. Make every portal feel like one platform with one shared identity layer.
2. Turn intake into an AI concierge flow, not a form collection flow.
3. Build a property timeline that combines handover, warranties, issues, appointments, and updates.
4. Add room and image understanding so the platform can infer what a user is looking at and what it means.
5. Expose operational intelligence to developers so the system gets more valuable as usage grows.
